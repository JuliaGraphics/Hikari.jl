Hikari.jl

Spectral path tracing in Julia, on Vulkan and Metal GPUs

Get Started
Materials
View on GitHub

Spectral wavefront path tracing

pbrt-v4's volumetric path tracer with hero-wavelength spectral transport, run as a wavefront of GPU kernels that Lava compiles from Julia, with hardware ray tracing where the GPU has it.

Volumes and clouds

Delta tracking with null scattering for fog, smoke and clouds, including sparse NanoVDB volumes.

Blender's materials and node graphs

Principled, Glass, Metallic and the other shader nodes, with Blender's names and defaults, driven by images or procedural node graphs.

Lights

Point, spot, directional, area and environment lights, with BVH light sampling for scenes with many emitters.

Checked against pbrt-v4

The test suite renders a pbrt-v4 reference set and compares every scene with pbrt's own render.

Denoising and Makie

OIDN denoising with albedo and normal guides. RayMakie renders any Makie scene with Hikari.

Gallery

Rendered with Hikari through RayMakie. The scenes are in SimonDanisch/RayDemo; select a picture for the full render.
